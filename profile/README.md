# HuiaHub

AI tools, open-source projects and agent skills, checked against their own sources and dated.

- **Tools:** pricing, free tiers and API access from the vendor's own pages, with the date checked.
- **Projects:** GitHub stars and releases, scored with published weights (the Huia Project Score).
- **Agent skills:** a security note on every skill: scripts, network access, hooks, secret requests.
